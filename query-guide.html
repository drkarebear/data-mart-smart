Question first, report second

Find the Right Data

Choose the question closest to yours. Each option gives you one strong starting report and the distinction that matters most.

What are you trying to find out?

How many students are there?

Start with: Student Annual/Term Count.

Use this for distinct students. Do not substitute course enrollments.

Open the Student Headcount guide →

How many courses or sections are being offered?

Start with: Course Details when you need identifiable courses. Use Credit Courses/Sections for broader section, enrollment, or FTES summaries.

Open the course and section guide →

Is enrollment growing or declining?

Start with: a consistent course or enrollment report across comparable terms or years.

Open the trend guide →

How are students doing in courses?

Start with: Retention/Success Rate.

Keep the enrollment denominator beside the rate.

Open the success and retention guide →

What does the grade pattern look like?

Start with: Grade Distribution.

Grade composition is not the same measure as the CCCCO success rate.

Open the Grade Distribution guide →

How many degrees or certificates were awarded?

Start with: Program Awards.

Award Count counts awards, not unique graduates.

Open the Program Awards guide →

How does one college compare with another?

Start with: the report that matches the measure you care about, then keep the period and population consistent.

Compare comparable exports →

I need services, staffing, transfer, wage, or another specialized report

Start with: the report guides by Data Mart area.
