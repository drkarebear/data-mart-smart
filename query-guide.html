Find the Right Data Source

Choose the question closest to yours. The recommendation is a starting point, not a rule that says you can use only one system.

What are you trying to find out?

How are students succeeding, completing, or transferring?

Start with: DataVista.

Use the broader student-outcome environment, then move to a cohort view when the question follows the same students over time.

Open DataVista guidance →

Where are there equity gaps?

Start with: DataVista.

Use the Student Equity and Achievement report or equity-focused Insights, and keep the denominator and suppression rules visible.

Open Equity guidance →

How many sections or enrollments are there over time?

Start with: DataVista for the broad multi-year picture.

Use Data Mart when you need a more specific course/section report or term-level detail.

See the DataVista route →

What grades were awarded?

Start with: Data Mart Grade Distribution.

This is a report-specific question where Data Mart remains especially useful.

Open the Grade Distribution guide →

I need identifiable course or section detail.

Start with: Data Mart Course Details or Credit Courses/Sections.

Then verify current local scheduling detail in your SIS when the decision is operational.

Open the course and section guide →

Should we add, reduce, or move sections next term?

Start with: local institutional data.

Current enrollment, waitlists, fill, schedule, modality, and cancellations matter more than lagged statewide data.

Open Enrollment Planning guidance →

Do we need more faculty or another resource?

Start with: local staffing/operational data, then add statewide context.

Avoid turning one FTES, section, or success metric into a staffing formula.

Open Staffing & Resources guidance →

I'm writing program review.

Start with: a combination.

DataVista for the broad story, Data Mart when a specific report fills a gap, and local data for current operations.

Open the Program Review guide →

CCC Data Smart

CCC Data Smart is an independent, faculty-led educational project. It is not an official California Community Colleges Chancellor's Office, DataVista, Data Mart, or local-college product and is not funded, sponsored, or endorsed by those entities. Data systems and definitions change. Verify consequential findings against current official CCCCO documentation and the appropriate local institutional sources.
