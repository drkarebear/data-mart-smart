Watch for

Watch for Legacy Reports

Matriculation Is Historical

The live Matriculation report currently ends at Spring 2014. For newer student-success-service activity, begin with Student Success Services Student Count rather than assuming Matriculation is current.

Report-Specific Definitions Matter

Do not assume every Student Services report uses the same headcount rules. Some service reports have their own notes, annual-unduplicated logic, or population definitions.

For example, the Special Population/Group Counts report currently states a different STD7 headcount-status set than the general Annual/Term Student Count report. Follow the note for the report you are actually using.

Do this

A Good Student Services Workflow

  1. Name the service or population

    Do not begin with the generic Student Services menu alone.

  2. Open the matching report

    Use the report whose population definition best matches the question.

  3. Choose term or annual period carefully

    Some reports label annual counts as unduplicated.

  4. Read the live report notes

    Definitions can differ from the general student headcount logic.

  5. Use demographic breakouts only when they support the question

    Avoid adding every available field.
