Enough evidence to tell the story, not a data dump

I'm Writing a Program Review

Do not start by choosing DataVista or Data Mart. Start with each CPR question and use the simplest source that answers it well.

The easiest program-review workflow

1

Term, course, grade, section, or award question?

Start with Data Mart. It is often the cleanest route for Fall-to-Fall activity, Course Details, Retention/Success, Grade Distribution, and Program Awards.

Open the Data Mart quick guide

2

Equity, cohort, pathway, completion, transfer, or annual outcome question?

Start with DataVista. Use its longitudinal and integrated-outcomes framework when that structure improves the question.

3

Current demand, scheduling, staffing, or resources?

Start with local data. Statewide sources are context, not live operations.

A lean evidence set

1. Scale and demand

Use comparable terms and local current data to understand sections, enrollments, students, fill, and demand.

2. Course outcomes

Use Data Mart for term-specific success/retention or grades; DataVista for broader annual patterns.

3. Equity and progression

Use DataVista when the question depends on disaggregation, cohort progression, completion, or transfer.

4. Current operations

Add local scheduling, waitlist, FTEF, staffing, modality, and resource evidence.

5. Interpretation

State what the evidence shows, what it does not establish, and what action or next question follows.

Keep the method reproducible

  1. Write the CPR question in plain language.
  2. Name the unit: students, enrollments, sections, awards, FTES, rate, or cohort.
  3. Choose the simplest valid source.
  4. Document population, term/year, metric, denominator, and filters.
  5. Use comparable periods for trends.
  6. Add local context before explaining why a pattern occurred.

Do not force DataVista into every question

For a simple term-specific course or count question, Data Mart may be easier and more transparent. Use DataVista where its cohort, equity, pathway, completion, transfer, or integrated-outcomes structure actually adds value.

Explore Data and the Program Review Dashboard are strongest with Data Mart-style exports. Use them to organize evidence after you have confirmed that the files answer comparable questions.
