Task guide: program review

I’m Writing a Program Review

Build a compact evidence set that describes program scale, change over time, student outcomes, and completion—then use it to support reflection rather than merely fill a table.

In a Hurry?

  1. Define the program and the review period before pulling anything.
  2. Pull a multi-year participation trend: headcount or enrollments, depending on the question.
  3. Pull sections and, where useful, FTES to show instructional activity.
  4. Pull success/retention and awards when they fit the program.
  5. Add local context, identify limitations, and end with the next question or action.

Evidence to Pull From Data Mart

  • Annual/Term Student Count for distinct student participation
  • Course Details or Credit Courses/Sections for offerings and enrollments
  • FTES for instructional activity
  • Enrollment Retention and Success Rate for outcomes
  • Program Awards for completions
  • consistent multi-year comparisons rather than isolated years

Evidence to Add From Your College

  • prior program review goals and action items
  • current curriculum and program maps
  • live scheduling, fill rates, waitlists, and cancellations
  • faculty/staff changes and vacancies
  • student feedback and local equity evidence
  • resource requests and evidence of what happened after prior requests

Questions the Data Should Help You Ask

  • What changed since the previous review?
  • Which changes appear persistent?
  • Are participation, offerings, outcomes, and awards telling the same story?
  • What local change might provide context?
  • What should we investigate or try next?

Do Not Let One Number Make the Decision

A program is not its enrollment, success rate, or award count. Program review should combine multiple measures with professional judgment, student experience, curriculum, and institutional context.

When Data Mart Is Not Enough

Bring in your institutional research office or another appropriate local expert when the question requires student-level longitudinal analysis, a locally defined cohort, confidential information, live operational data, causal analysis, or a high-stakes institutional conclusion.

Method Language You Can Adapt

For this review, I examined comparable CCC Data Mart measures across the selected years using the same geography, population, and program/course definition. I treated the results as descriptive evidence and paired them with local program information before drawing conclusions.
