Example Data Mart Questions

These examples show how a real institutional question becomes a report, measure, population, and set of cautions. The examples teach the method; they do not provide fabricated results.

Example 1: Compare English Sections Across Colleges

Question: “How many English sections did each college in my district offer in Fall 2026?”

Best starting report
Course Details when identifiable local courses matter
Measure
Sections Count
Time period
Fall 2026
Population
Selected colleges and a documented definition of “English”
Main caution
Local ENGL/ENGLISH prefixes, TOP-code scope, and linked lecture/lab or support records can change the count

Follow the full section-count recipe →

Example 2: Compare Communication Studies Awards

Question: “How many associate degrees in Communication Studies did each college award?”

Best starting report
Program Awards
Measure
Award Count
Time period
One consistent academic year or a consistent multi-year range
Population
Selected colleges, relevant program/TOP classification, and associate-degree award type
Main caution
Award Count is not automatically a count of unique graduates, and different award categories should not be combined casually

Example 3: Examine a Five-Year Enrollment Trend

Question: “Has enrollment in our program declined over the last five fall terms?”

Best starting report
Depends on whether “enrollment” means distinct students or course enrollments
Measure
Define Student Count or Enrollment Count before proceeding
Time period
Fall-to-Fall for five consistent terms
Population
Same program/course definition each year
Main caution
Course renumbering, TOP-code changes, or changing local prefixes can create an artificial trend

Follow the enrollment-trend recipe →

Example 4: Compare Course Success

Question: “How does our success rate compare with neighboring colleges?”

Best starting report
Enrollment Retention and Success Rate
Measure
Success Rate and the underlying enrollment count
Time period
Same term or year for every college
Population
Same course/TOP and credit-status definition
Main caution
A difference in rates is descriptive; it does not establish why the difference exists

Follow the success-and-retention recipe →

Example 5: Ask an Equity Question

Question: “Are there meaningful differences in course outcomes among student groups?”

Best starting report
A report that supports the desired outcome measure and demographic breakout
Measure
Define the outcome, numerator, denominator, and underlying N
Time period
Use the same period across groups
Population
Keep course/program definitions consistent
Main caution
A disparity is a signal to investigate, not an explanation of why the disparity exists
