Example CCC Data Questions

These examples show how the question determines the source. They teach the method and do not provide fabricated results.

Example 1: Program activity over time

Question: “How has English instructional activity changed over the last five years?”

Start with: DataVista for program-level sections, enrollments, online/DE sections, calculated FTES, and related multi-year measures.

Add: local current schedule/fill data if the finding will inform future scheduling.

Main caution: keep the same program/TOP definition across years and note that DataVista calculated FTES is not official CCFS-320 FTES.

Example 2: A current scheduling decision

Question: “Should we add another evening section next semester?”

Start with: local enrollment, waitlists, fill rates, cancellations, schedule, and staffing.

Add: DataVista or Data Mart historical context only after the live demand is clear.

Main caution: lagged statewide data cannot answer what is filling right now.

Example 3: Grade patterns

Question: “What grades were awarded in this course across several colleges?”

Start with: Data Mart Grade Distribution.

Add: DataVista for broader success/equity context if the grade pattern raises a larger question.

Main caution: a grade distribution is descriptive and does not establish why colleges differ.

Example 4: Equity

Question: “Are there meaningful differences in an outcome among student groups?”

Start with: DataVista and a defined outcome/denominator.

Add: local student experience, curriculum, services, and institutional context.

Main caution: suppressed values are not zero, and a disparity is not a diagnosis.

Example 5: Program review

Question: “What is the clearest evidence set for our comprehensive program review?”

Start with: the specific program-review question.

Use: Data Mart for term/report questions, DataVista for cohort/equity/pathway/completion/transfer or integrated annual outcomes, and local data for current operations.

Main caution: more metrics do not automatically make the review stronger.

Data Mart Smart

Data Mart Smart is an independent, faculty-led educational project. It is not an official California Community Colleges Chancellor's Office, DataVista, Data Mart, or local-college product and is not funded, sponsored, or endorsed by those entities. Data systems and definitions change. Verify consequential findings against current official CCCCO documentation and the appropriate local institutional sources.
