Designed for access from the start

Accessibility

Data Mart Smart aims to meet or exceed WCAG 2.2 Level AA and to make practical data guidance usable with keyboards, screen readers, zoom, reflow, and other access technologies.

Accessibility target: WCAG 2.2 AA

Current Design Practices

  • semantic headings and page landmarks;
  • a skip link to bypass repeated navigation;
  • descriptive link text;
  • visible keyboard focus indicators;
  • large interactive targets;
  • responsive layouts that reflow on smaller screens;
  • no essential information conveyed by color alone;
  • reduced-motion support;
  • accessible table headers and captions;
  • form controls with programmatic labels.

Screenshots and Data Examples

When screenshots are added to how-to guides, the goal is to provide meaningful alternative text or adjacent text instructions so the task does not depend on seeing the image.

Known Limitations

Links to external CCCCO pages and the CCC Data Mart itself lead to websites that are outside this project's control. Accessibility on those external pages may differ from this site's design.

Beyond the checklist

Cognitive and Attention-Friendly Design

The site also uses cognitive-accessibility practices intended to help busy or overloaded users find what matters without holding the whole page in working memory.

  • short “In a Hurry?” summaries near the top of detailed guides;
  • consistent visual roles for actions, meanings, cautions, methods, and next questions, with text labels so color is never the only cue;
  • clear breadcrumbs, jump links, and repeated page patterns to make it easier to reorient;
  • plain-language headings, short blocks of text, and limited line length for scanning;
  • prominent next-action buttons for common tasks; and
  • no timed interactions, autoplay, or moving content required to use the site.

Ongoing Testing

The site should be tested with automated accessibility tools, keyboard-only navigation, browser zoom/reflow, and manual review as pages and interactive features are added.
