What This Prototype Is Doing


The CCCCO export is hierarchical: district totals, college totals, award-type totals, then individual TOP-coded program rows. The viewer reconstructs that hierarchy and turns the program rows into a filterable dataset.


Current scope: Program Awards Summary Excel exports. If this works well, the same approach can be extended to course sections, student headcount, success/retention, and other Data Mart exports.


Spreadsheet parsing uses SheetJS Community Edition 0.18.5 (Apache-2.0), loaded from jsDelivr. Your selected workbook is processed in the browser.
