The goal is a number you can explain

Data Mart Smart keeps distinctions such as distinct students, course enrollments, reported sections, awards, rates, and FTES visible because those measures answer different questions. When a denominator, overlap, or report definition matters, the caution stays with the result.

You can use the site without an institutional-research background. For consequential decisions, verify findings against current CCCCO documentation and the appropriate local institutional sources.
