Start with Data Mart. Switch tools when the question needs more.

Data Mart Smart is built around the fast, report-based Data Mart workflow. It also points you to DataVista when cohorts, equity, pathways, completion, transfer, labor-market outcomes, or other connected measures make the extra depth worthwhile.

Know when local data comes first →

The 10-second rule

How many / which course / which term / which grades? Data Mart. Same students over time / equity / pathways / completion / transfer? DataVista. What is happening right now? Local data. What should we do about it? Combine sources.

Understand the number →

Fast is useful only when the number still means what you think it means.

Data Mart Smart keeps distinctions such as students versus enrollments, snapshot versus cohort, reported sections versus locally understood classes, official versus calculated FTES, suppressed values, and incomplete years visible because those distinctions can change the meaning of a finding.

For consequential decisions, verify the result against the current metric definition and the appropriate local institutional source.
