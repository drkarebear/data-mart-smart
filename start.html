When Data Mart is not the best first stop

Same students over time, equity, pathways, completion, transfer

Use DataVista when its cohort and integrated-outcomes structure adds value.

Live enrollment, waitlists, staffing, scheduling, budget

Use local institutional data because Data Mart is not a live campus operations system.

Four distinctions that prevent bad conclusions

Student ≠ Enrollment

One student can generate several course enrollments.

Course ≠ Section

One course may have many sections, and local linked components can complicate interpretation.

Rate ≠ Count

Always identify the numerator, denominator, and underlying N.

TOP Code ≠ Local Prefix

A statewide program classification and a local subject prefix can produce different populations.

January 2026 Student Count change

The current Annual/Term Student Count report now uses distinct statewide, districtwide, and collegewide counts. Do not add college headcounts together to reconstruct a district or statewide distinct-student total.
