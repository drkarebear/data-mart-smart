Data Mart Made Simple

CCC Data Mart remains useful for detailed public MIS queries. Use it when your question needs a specific report, not automatically as the first stop for every institutional question.

When Data Mart is the right first stop

Data Mart is especially useful for detailed report-level questions such as grade distribution, course details, specific term tables, and traditional MIS exports. For broader student outcomes, equity, or pathway questions, start with DataVista. For live scheduling or staffing decisions, start locally.

What Is CCC Data Mart?

CCC Data Mart is a public California Community Colleges Chancellor's Office reporting portal built from Management Information System data submitted by community college districts. It summarizes reported and derived information about students, courses, services, outcomes, faculty, staff, and related areas.

Data Mart Is Not a Live College Registration System

Data Mart reflects information reported to the Chancellor's Office. It may not match a college's live SIS or class schedule at this moment. If your question contains words such as “today,” “right now,” or “currently enrolled,” a local institutional source may be more appropriate.

The Five Main Areas

Students

Headcount, enrollment status, unit load, demographics, FTES, and related student measures.

Courses

Sections, enrollments, FTES, course details, TOP codes, and academic-calendar information.

Outcomes

Success, retention, grades, awards, transfers, and wage outcomes.

Student Services

Financial Aid, EOPS, DSPS, CalWORKs, student-success services, and other service-related reporting.

Faculty & Staff

Staffing summaries and faculty/staff demographic reporting.

Your Question

The database's categories are useful, but your research question should still determine which report and measure you use.

A Better Way to Start

  1. Write the question in plain language. Example: “How many English sections did each college offer?”
  2. Decide what should be counted. Students? Enrollments? Sections? Awards? A rate?
  3. Define the population. Which colleges, courses, programs, groups, or TOP codes?
  4. Choose the time period. One term, an academic year, or a multi-year trend?
  5. Then choose the report. The report should match the measure, not just contain related words.

Three Distinctions to Learn First

Student Count ≠ Enrollment Count

A student can enroll in several courses. A count of people and a count of course enrollments answer different questions.

Course ≠ Section

One course may have many sections. Some locally linked instructional components may also appear as separate reported section records.

Rate ≠ Raw Count

A success percentage needs a denominator. Always look at the underlying N when it is available.

TOP Code ≠ Local Prefix

A TOP code classifies an instructional area; a subject prefix such as ENGL is a local course identifier.

One Important 2026 Change

The Annual/Term Student Count report was updated in January 2026. Current statewide and districtwide student counts are deduplicated distinct counts, so adding college headcounts together is not a safe way to reconstruct those totals.

Before You Publish a Number

Read the report's Notes & Links area, define what the number counts, and save the setup you used. If the result matters for program review, accreditation, staffing, funding, or another consequential decision, verify it against current official documentation.
