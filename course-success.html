Retention Here Has a Specific Report Definition

Do not interpret Data Mart retention as “the student stayed enrolled at the college.” The report defines retention from course-enrollment grade codes.

How to Set It Up

  1. Choose geography and term

    Use the same period and geography logic for every group or college you plan to compare.

  2. View the report

    Add only the dimensions needed to answer the question.

  3. Add College Name or demographic fields as needed

    Do not disaggregate simply because a field is available; use variables tied to the actual inquiry.

  4. Add the appropriate TOP level or course-status fields

    Examples can include transfer, degree-applicable, basic skills, or vocational status when relevant.

  5. Inspect counts and rates together

    A percentage without the underlying N can be misleading.

  6. Read the live notes

    The formulas depend on report-defined grade-code groups. If an unfamiliar grade code matters, verify it rather than guessing.

What the Counts Mean

What it means

Plain-language interpretation of the report measures
MeasureInterpretation
Enrollment CountCourse enrollments included in the report's defined grade-code population.
Retention CountIncluded enrollments that meet the report's retention-grade definition.
Success CountIncluded enrollments that meet the report's success-grade definition.
Retention RateRetention Count divided by the relevant Enrollment Count.
Success RateSuccess Count divided by the relevant Enrollment Count.

Watch for

Before Comparing Rates

  • same report;
  • same time period;
  • same course/TOP definition;
  • same credit/course-status population;
  • same numerator/denominator logic;
  • underlying N considered alongside the percentage.
What the Data Do Not Establish

Watch for

If College A has a higher success rate than College B, the report establishes a descriptive difference in the selected population. It does not by itself establish that one college teaches better, that one program is stronger, or why the difference exists.

You Found a Result. What Should You Ask Next?

What next

  • How large is the underlying enrollment count?
  • Does the difference persist across multiple terms?
  • Would disaggregation help identify a question without implying a cause?
