Why this project exists

About Data Mart Smart

Data Mart Smart is an independent, faculty-led educational project built to make CCC Data Mart easier to use well. It also helps faculty recognize when DataVista or local institutional data is the better tool for a particular question.

Why this exists

Data Mart is still a remarkably useful source for direct CCC reporting questions, but its report structure, terminology, and counting rules can be easy to misread. DataVista now adds richer cohort, equity, pathway, completion, transfer, and labor-market views, while local systems remain essential for current operations.

Data Mart Smart keeps Data Mart as the practical home base, then points elsewhere when another source better fits the question.

What this project tries to do

  • help users choose among DataVista, Data Mart, and local institutional data;
  • explain technical measures in plain language;
  • make snapshot, cohort, suppression, denominators, and incomplete years visible;
  • help users avoid double counting and mismatched comparisons;
  • show how to document a reproducible method;
  • separate what the data show from what they do not establish.

Independent project

Not an official CCCCO product

Data Mart Smart and CCC Data Coach are independent educational resources. They are not official California Community Colleges Chancellor's Office, DataVista, Data Mart, or local-college products and are not funded, sponsored, or endorsed by those entities.

Use official sources for verification

Reports, definitions, available years, and interfaces change. For consequential institutional decisions, verify key findings against current official CCCCO documentation and the appropriate local institutional research or data source.

Website + Coach

The website teaches reusable methods and practical data-literacy habits. The CCC Data Coach first uses a private, browser-based routing guide to help match a question to DataVista, Data Mart, or local institutional data. An optional external Playlab assistant can support a longer conversational follow-up.
