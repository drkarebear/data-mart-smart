Compare several exports

Compare Colleges or Build a Trend

Open two or more exports from the same Data Mart report. Data Mart Smart checks whether they are comparable, then helps you chart one consistent measure across colleges or time periods.

Have one Program Awards export with several annual columns and several colleges? Use District Compare & Trends instead. It can follow each college as its own line across the selected years.

📈 One Measure, Several Comparable Files

This tool is deliberately stricter than the one-file Explorer. It will not combine different report types, and it does not silently turn missing values into zero.

Same reportUse the same Data Mart report for every file.
Same definitionKeep the population, TOP or course definition, and measure consistent.
One thing changesFor the cleanest trend, vary time while holding the institution constant. For a college comparison, hold the period constant.
Your spreadsheets stay in this browser tab. Data Mart Smart reads the selected files locally with JavaScript. The spreadsheets themselves are not uploaded to Data Mart Smart.

Reports Supported for Multi-File Comparison




👥 Student Headcount
Compare the same demographic category across colleges or periods.


📚 Course Details
Compare reported section counts for the same course, prefix, title, or TOP area.


📈 Credit Courses/Sections
Compare the same displayed row using Section Count, Enrollment Count, or FTES.


🎯 Success & Retention
Compare counts or rates. Rates are recalculated from the underlying counts.


📊 Grade Distribution
Compare the same grade category as a count or share of a selected TOP area.


🎓 Program Awards
Compare the same program and award type without treating awards as unique graduates.




Why not every export? The basic one-file table view can chart many exports, but multi-file comparison has a higher risk of mixing totals, subtotals, populations, or incompatible definitions. Data Mart Smart only enables comparison logic where we have tested the report structure.
