Use the simplest source that can answer the question

Data Mart, DataVista, or Local Data?

Start with Data Mart for many direct report questions. Move to DataVista when cohorts, equity, pathways, completion, transfer, labor-market outcomes, or a connected annual framework add something you actually need. Use local data for what is happening now.

Routing reviewed: September 6, 2026

The fast rule

Listen to the wording of your question.

1

How many? Which course? Which term? Which grades?

Start with Data Mart. It is often the shorter path for a specific term, course, grade, section, student-count, service, or staffing report.

See the Data Mart quick guide

2

What happened to the same students over time? Where are the equity gaps?

Use DataVista when you need its extra depth. It is strongest for cohorts, pathways, equity, completion, transfer, labor-market outcomes, and statewide initiative metrics. Broad views can take longer to load.

See when DataVista is worth the wait

3

What is happening right now?

Start with local institutional data. Use your SIS, Power BI, scheduling, HR, budget, or institutional-research source for live enrollment, waitlists, fill, staffing, and local definitions.

See when local data comes first

4

What should we do about it?

Use a combination. Program review, accreditation, hiring, resource requests, and enrollment planning usually need more than one source.

See the program-review evidence guide

If DataVista feels slow, narrow the job

For a simple term, course, grade, or count question, Data Mart may get you to a reproducible table with fewer steps. The official DataVista release webinar also notes that selecting All Students loads a large amount of data and can take longer. When you do need DataVista, go directly to Single Metric if you already know the measure instead of loading a broader view you do not need.

See the DataVista speed tips

Newer does not mean better for every question

Use DataVista for the questions its cohort, equity, pathway, completion, transfer, and integrated-outcome structure improves. Use Data Mart when a direct report already answers the question cleanly.
