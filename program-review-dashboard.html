Program Review Dashboard

Open several Data Mart exports from the same program or discipline. Data Mart Smart keeps the measures separate, connects what can be connected safely, and builds a compact evidence picture for reflection and planning.

📋 One Program, Several Kinds of Evidence

This dashboard can combine different report families because program review needs more than one number. It does not merge unlike measures into one score.

Keep measures distinctSections, enrollments, FTES, success, grades, and awards answer different questions.
Use one program definitionSix-digit TOP is used across report families when it is available. Local prefixes may not match TOP exactly.
Show the periodEvery metric keeps its own term or academic year visible so unlike periods are not silently treated as the same.

A Dashboard Is Evidence, Not the Program Review
Data Mart can describe participation, instructional activity, outcomes, and awards. Program review still needs local curriculum, scheduling, staffing, student experience, prior goals, and professional judgment. The dashboard should help you ask better questions, not make the decision for you.
