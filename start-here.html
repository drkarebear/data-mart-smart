A useful rule

Do not choose a database first.

Question → source → population → metric → denominator → interpretation → limitation → next question.

Five distinctions worth learning early
  • Distinct students are not the same as course enrollments.
  • Snapshot and cohort views answer different questions.
  • Suppressed or masked values are not automatically zero.
  • Reported sections are not automatically the same as locally understood classes.
  • Statewide data are not a substitute for a live local SIS when the decision is about right now.
