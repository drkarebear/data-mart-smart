A useful rule

Use the simplest valid source.

Question → simplest source that answers it → population → measure → denominator → interpretation → limitation. Data Mart is often the shorter route; switch to DataVista when its extra structure answers something Data Mart does not answer as well.

A 10-second shortcut

Term, course, count, grade, award, service, or staffing: Data Mart. Cohort, equity, pathways, completion, transfer, or labor-market outcomes: DataVista. Current enrollment, waitlists, fill, staffing, or scheduling: local data. Program review or a decision: combine sources.

Five distinctions worth learning early
  • Distinct students are not the same as course enrollments.
  • Snapshot and cohort views answer different questions.
  • Suppressed or masked values are not automatically zero.
  • Reported sections are not automatically the same as locally understood classes.
  • Statewide data are not a substitute for a live local SIS when the decision is about right now.
