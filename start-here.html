Five Terms That Prevent a Lot of Mistakes

Student Count
Distinct students in the report’s defined population, not the number of course enrollments.
Enrollment Count
Course enrollment records. One student may contribute more than one enrollment.
Section
A reported class section. Linked lecture/lab structures can create more than one reported section for what people informally call one class.
FTES
A measure of instructional activity, not a count of students, enrollments, or faculty.
Award Count
Reported degree/certificate awards. One student can receive more than one award.
