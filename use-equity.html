Equity inquiry

Use Data for Equity Inquiry

Start in DataVista for the statewide equity picture, then use local evidence to understand context and design a response.

Start with DataVista

DataVista includes the Student Equity and Achievement Program report and equity-focused visualizations. It also supports disaggregations across multiple student characteristics, depending on the metric and student group.

Need the official SEA frame?

Use the Student Equity and Achievement Program report.

Exploring a broader pattern?

Use equity-focused Insights or a relevant metric in Single Metric/Metric Themes.

Before comparing groups

  1. Confirm the denominator. Ask what population each percentage is calculated from.
  2. Keep the student group consistent. Snapshot and cohort comparisons answer different questions.
  3. Check suppression. Small groups can be masked, and complementary suppression can hide an additional group.
  4. Check completeness. Recent cohort outcomes may still update.

A disparity is not a diagnosis

The data can show that outcomes differ. They do not by themselves establish why. Add student experience, curriculum context, service use, scheduling, institutional practices, and other evidence before attributing a cause.

Where Data Mart still helps

Use Data Mart when the equity question specifically requires a report such as Grade Distribution or another detailed public MIS table not represented the way you need in DataVista.

Where local data matters

Use local evidence to understand interventions, course sequencing, modality, faculty practices, support-program participation, current enrollment patterns, and other campus-specific conditions.
