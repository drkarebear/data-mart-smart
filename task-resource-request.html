Resource allocation

I Need Evidence for a Resource Request

State the problem first. Then choose only the evidence that shows the need, its scale or persistence, and what the requested resource is expected to change.

Build the case in this order

  1. Name the local need. What is students' or the program's current barrier, capacity problem, or unmet need?
  2. Use local evidence first. Add workload, capacity, cost, access, waitlist, technology, facilities, or service-gap information that directly describes the problem.
  3. Add DataVista context. Use multi-year program activity, student outcomes, equity, or other defined metrics only when they help show why the need matters.
  4. Use Data Mart selectively. Pull a specific detailed report when it fills a gap, such as course/section activity, student services, or faculty/staff context.
  5. Connect the request to an expected result. Explain what the investment should change and how you will know whether it helped.

Do not manufacture urgency with one big number

A large headcount, FTES value, low success rate, or peer comparison does not automatically establish priority. Resource allocation is a planning and governance decision. Evidence should clarify the need, not pretend the decision is automatic.

Useful evidence questions

  • Who is affected, and how do we know?
  • Is the need persistent across time?
  • What capacity or access problem is visible locally?
  • What student outcome or program trend provides useful context?
  • What would change if the request were funded?
  • What evidence would we review afterward?

Method language you can adapt

I documented the local capacity or student-need problem first, then selected statewide measures that directly related to that need. I used multi-year evidence where appropriate and paired it with local cost, workload, access, and planning information before making the resource request.
