# Data Mart Smart

Data Mart Smart is an independent, faculty-led guide to choosing, understanding, and responsibly using California Community Colleges data.

## Core idea

Do not choose a database first. Start with the institutional question, then choose the source, population, metric, denominator, interpretation, limitation, and next question.

## Three-source model

- **DataVista** for broad student outcomes, equity, pathways, completion, transfer, and multi-year program context.
- **CCC Data Mart** for detailed public MIS queries such as grade distribution, course details, and traditional report exports.
- **Local institutional data** for current enrollment, waitlists, scheduling, staffing, FTEF, and campus-specific operational questions.

## September 2026 revision

The site was broadened from the original Data Mart Smart project after review of current DataVista documentation, 2026 Metric Definition Dictionaries, suppression guidance, and the live DataVista interface. Existing Data Mart report guides and browser tools were preserved as deep-dive resources.

## Independence

Data Mart Smart is not an official California Community Colleges Chancellor's Office, DataVista, Data Mart, or local-college product. Verify consequential findings against current official documentation and appropriate local institutional sources.
