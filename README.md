# Data Mart Smart

A practical, faculty-led guide to using California Community Colleges Data Mart.

## Explore Data

`explore-data.html` is the browser-based export explorer. It identifies supported CCC Data Mart exports and applies report-specific parsing, filtering, visualization, and method-documentation rules.

Working modules in v16:
- Student Headcount
- Course Details
- Credit Courses/Sections in summary mode
- Enrollment Retention and Success Rate
- Grade Distribution
- Program Awards

`student-headcount.html` also includes a dedicated Student Headcount visualizer so users can upload that report directly from its guide page.

Selected spreadsheets are processed locally in the browser. Data Mart Smart is an independent educational project and is not an official California Community Colleges Chancellor's Office product.
