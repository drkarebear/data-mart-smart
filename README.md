# Data Mart Smart

A practical, faculty-led guide to using California Community Colleges Data Mart.

## Explore Data

`explore-data.html` is the current browser-based export explorer. It automatically identifies supported CCC Data Mart exports and applies report-specific parsing and visualization rules.

Working modules in v14:
- Program Awards
- Enrollment Retention and Success Rate

Recognized for future modules:
- Student Headcount
- Grade Distribution
- Course Details
- Credit Courses/Sections

Selected spreadsheets are processed locally in the browser. Data Mart Smart is an independent educational project and is not an official California Community Colleges Chancellor's Office product.
