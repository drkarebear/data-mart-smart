Use Data in Resource and Staffing Conversations

Use public trend and workload context to strengthen resource conversations while keeping the actual allocation decision tied to local planning, budget, workload, and governance processes.

What Data Can Help You Do

Data can help show program scale, trends in participation, instructional activity, awards, service demand, or staffing context. That can make a resource request more transparent and connected to institutional priorities.

Useful Data Mart Starting Points

  • sections and enrollment counts
  • FTES
  • student headcount trends
  • program awards
  • faculty/staff staffing summaries
  • student-services participation

What to Pair With Data Mart

  • local budget and expenditure data
  • faculty load and assignment data
  • vacancy and hiring information
  • program review priorities
  • facilities/technology needs
  • institutional resource-allocation criteria

Questions to Bring to the Conversation

  • What student or program need does the resource address?
  • Is the need persistent over time?
  • What other evidence supports the request?
  • What outcome would indicate the investment is helping?
  • What local data are required before a decision?

Important Boundary

Data Mart can support a resource conversation, but it should not mechanically determine funding, hiring, or staffing. Local governance, workload, budget, program need, and institutional priorities are essential.

Turn the Purpose Into a Query

If you know the decision or conversation but not the report, use Find the Right Report or CCC Data Mart Coach.
