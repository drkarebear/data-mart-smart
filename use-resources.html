Staffing and resources

Use Data in Staffing and Resource Conversations

Start with the local problem the resource would solve. Then use statewide data to show scale, trend, and student context.

Start with the operational need

For staffing, that may include current FTEF, full-time/adjunct load, vacancies, overload, sections that must be staffed, schedule coverage, and workload. For equipment or other resources, document the instructional or student-service problem directly.

Add statewide context selectively

DataVista

Use for multi-year program activity, student outcomes, equity, and other context that shows why the resource matters to the program's work.

Data Mart

Use when a specific public report adds evidence, such as course/section activity or faculty/staff reporting.

No single metric is a hiring formula

FTES, section count, headcount, success rate, and awards each answer different questions. A credible staffing request explains the operational need and uses several measures only when they are relevant.

Make the chain visible

Need → evidence → consequence → requested resource → expected benefit → how you will know it helped.
