Where the guidance comes from

Sources and Methods

CCC Data Smart prioritizes current official California Community Colleges Chancellor's Office documentation and distinguishes statewide metrics from local operational data.

Major DataVista revision: September 2026

Source priority

  1. current live DataVista and CCC Data Mart pages;
  2. current official CCCCO metric definitions, background information, and report-specific notes;
  3. current MIS Data Element Dictionary definitions;
  4. current local institutional sources for campus-specific operational claims;
  5. older official manuals or training materials only when they still match current behavior.

How guidance is written

Each guide tries to make the same chain visible: question → source → population → metric → denominator → interpretation → limitation → next question. When a statewide system does not support a claim, the site directs the user to local institutional evidence instead of filling the gap by assumption.

Corrections and versioning

Interfaces, reports, definitions, and update schedules can change. The site therefore treats live official documentation as authoritative when older guidance conflicts with current behavior.

CCC Data Smart

CCC Data Smart is an independent, faculty-led educational project. It is not an official California Community Colleges Chancellor's Office, DataVista, Data Mart, or local-college product and is not funded, sponsored, or endorsed by those entities. Data systems and definitions change. Verify consequential findings against current official CCCCO documentation and the appropriate local institutional sources.
