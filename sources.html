Where the guidance comes from

Sources and Methods

Data Mart Smart prioritizes current official California Community Colleges Chancellor's Office documentation and distinguishes current report behavior from older guidance.

Current site guidance developed for Fall 2026

Source Priority

  1. current live CCC Data Mart report pages and their Notes & Links;
  2. current official CCCCO documentation and MIS updates;
  3. current MIS Data Element Dictionary definitions;
  4. current TOP/CIP transition guidance when classification changes matter;
  5. older official manuals or training materials only when still applicable.

Core Sources

CCC Data Mart

The live reporting environment is the primary source for current report availability, interface behavior, time-period selectors, and report-specific notes.

Open the official CCC Data Mart

MIS Data Element Dictionary

Used for formal definitions of course, section, student, enrollment, award, and other reported elements.

Open the CCCCO Data Element Dictionary

Taxonomy of Programs

Used to understand TOP classifications. Current Data Mart reports remain TOP-based while the system transitions toward CIP reporting.

How Guidance Is Written

Each practical guide aims to identify the user's likely research question, the appropriate report, the measure being counted, the population and time period, and any methodological issue that could change the interpretation.

Important 2026 Notes

  • The Annual/Term Student Count report changed in January 2026, including deduplicated statewide and districtwide counts.
  • Current Data Mart remains TOP-based even as statewide TOP-to-CIP transition work continues.
  • “Latest available” varies by report because student, course, award, transfer, wage, and employee data follow different submission cycles.

Corrections

If you identify a likely error, verify it against the current official source before relying on this site's wording. A correction/contact workflow can be added once the project's public contact method is finalized.

Data Mart Smart

Data Mart Smart is an independent, faculty-led educational project. It is not an official California Community Colleges Chancellor's Office or CCC Data Mart product and is not funded, sponsored, or endorsed by those entities. Guidance may contain errors or become outdated as Data Mart changes. Verify consequential findings against current official CCCCO documentation and appropriate local institutional sources.
