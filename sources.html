Sources and Methods

Data Mart Smart prioritizes current official California Community Colleges Chancellor's Office documentation. The site treats Data Mart as the practical first stop for many direct report questions, while routing to DataVista or local data when those sources better fit the research question.

Major DataVista revision: September 2026

Source priority

  1. current live DataVista and CCC Data Mart pages;
  2. current official CCCCO metric definitions, background information, and report-specific notes;
  3. current MIS Data Element Dictionary definitions;
  4. current local institutional sources for campus-specific operational claims;
  5. older official manuals or training materials only when they still match current behavior.

How guidance is written

Each guide tries to make the same chain visible: question → source → population → metric → denominator → interpretation → limitation → next question. When a statewide system does not support a claim, the site directs the user to local institutional evidence instead of filling the gap by assumption.

How source routing was reviewed in September 2026

The routing model was checked against the current live Data Mart and DataVista interfaces. Data Mart continues to provide direct reports for Annual/Term Student Count, Course Details, Credit Courses/Sections, Retention/Success Rate, Grade Distribution, Program Awards, Student Services, and Faculty & Staff. DataVista provides Single Metric, Metric Themes, Reports, Insights, the Comprehensive Student Report, cohort views, equity reporting, and labor-market/outcome views.

The resulting rule is intentionally practical: use Data Mart first for many direct report and term questions; use DataVista when its cohort, equity, pathway, completion, transfer, labor-market, or integrated-outcomes structure adds value; use local data for current operations. When two sources can validly answer the same question, the site favors the simpler reproducible workflow.

How the browser-based Coach works

The first-step CCC Data Coach is a transparent rule-based router, not a generative AI system. It matches ordinary-language question patterns to the same source-selection guidance documented across this site. It favors Data Mart for direct term/report questions, DataVista when cohort/equity/pathway/completion/transfer or integrated outcomes add value, and local institutional data when the question depends on current operations or campus-specific definitions. The question is processed in the browser and is not stored by Data Mart Smart.

Corrections and versioning

Interfaces, reports, definitions, and update schedules can change. The site therefore treats live official documentation as authoritative when older guidance conflicts with current behavior.

Data Mart Smart

Data Mart Smart is an independent, faculty-led educational project. It is not an official California Community Colleges Chancellor's Office, DataVista, Data Mart, or local-college product and is not funded, sponsored, or endorsed by those entities. Data systems and definitions change. Verify consequential findings against current official CCCCO documentation and the appropriate local institutional sources.
