# Routing Update - September 6, 2026

This revision changes Data Mart Smart from a broadly DataVista-first model to a **simplest-valid-source** model.

## Core routing

- **Data Mart first:** specific term/report questions, student counts, Course Details, sections/enrollments, Grade Distribution, term Retention/Success, awards, Student Services, Faculty & Staff.
- **DataVista first:** cohorts, equity, pathways, completion, transfer, labor-market outcomes, statewide initiative metrics, integrated annual student-outcome questions.
- **Local data first:** live enrollment, waitlists, fill, scheduling, staffing, FTEF, budget, and local definitions.
- **Combination:** program review, accreditation, hiring, resource requests, and other decisions.
