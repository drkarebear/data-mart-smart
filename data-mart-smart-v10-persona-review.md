# Data Mart Smart v10 Persona Usability Review

## Summary
The site now supports five very different user types without requiring them to know Data Mart terminology first. The biggest remaining risk was entry-point overload, so v10 adds a single Start Here page that routes users by situation rather than by report name.

## Faculty member who dislikes data
- PASS: Can I tell what to click without knowing report names?
- PASS: Can I get a useful answer in under 3 minutes?
- PASS: Does the page explain why the number matters?
- PASS: Does it avoid jargon or define it nearby?
- PASS: Does it prevent me from thinking a difference automatically means quality?

## Department chair under a deadline
- PASS: Can I start from a task like program review, hiring, scheduling, or resource request?
- PASS: Can I see exactly what to pull from Data Mart versus locally?
- PASS: Can I copy a method statement into a report?
- PASS: Can I find cautions before I accidentally overclaim?
- PASS: Can I move directly to a related recipe?

## Dean or administrator
- PASS: Can I compare units or colleges without mixing measures?
- PASS: Does the site separate evidence from decision authority?
- PASS: Does it surface local context and governance requirements?
- PASS: Does it discourage ranking without scale/context?
- PASS: Can I use it for planning and institutional-effectiveness questions?

## IR professional
- PASS: Are definitions, denominators, and units of analysis explicit?
- PASS: Does the site distinguish public Data Mart evidence from local IR data?
- PASS: Does it flag deduplication, report-specific definitions, and lag?
- PASS: Does it avoid causal claims from descriptive data?
- PASS: Does it encourage reproducibility and source verification?

## First-time Data Mart user
- PASS: Can I begin with a plain-language question?
- PASS: Can I tell which report family to use?
- PASS: Are student count, enrollment, section, FTES, and award count distinguished?
- PASS: Is there a setup checklist?
- PASS: Can I recover if I already exported data?

## Cross-site safeguards confirmed
- PASS: plain-language question entry
- PASS: task guides
- PASS: in-a-hurry shortcuts
- PASS: method language
- PASS: data/local evidence distinction
- PASS: causation warning
- PASS: comparison safeguards
- PASS: query checklist
- PASS: export recovery
- PASS: current/legacy data page
- PASS: inquiry conversation page

## Changes made in v10
- Added Start Here page for overwhelmed/first-time users.
- Added homepage Start Here CTA.
- Added Start Here to primary navigation.
- Added five-term micro-glossary.
- Added explicit 'When Data Mart Is Not Enough' callout to task guides.
- Preserved purpose-first, task-first, report-first, export-first, and inquiry-first paths.
