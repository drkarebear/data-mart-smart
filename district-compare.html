Best exports for District Compare & Trends


District Compare currently has report-specific support for Course Details, Program Awards, Success & Retention, Grade Distribution, and Student Headcount. The multi-college line graph works with one Program Awards export that contains multiple annual columns. Choose an award type such as A.A. or A.A.-T, choose the latest 5 years, latest 10 years, all years, or a custom range, and follow the same colleges across time.


Why not every Data Mart report yet?
Some Data Mart exports do not identify college, program, period, and measure in a structure that can be compared safely without additional testing. Data Mart Smart will not guess at those fields.
If the Excel reader will not load
The comparison page itself should still load and the built-in example should still work. Excel support is loaded only when you choose an .xlsx or .xls file. If that external reader is blocked or slow, export the same Data Mart result as CSV and try again; CSV is read locally without that dependency.
