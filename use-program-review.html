Purpose pathway: reflection and improvement

Use Data for Program Review

Use evidence to describe what is happening in a program, identify changes over time, test assumptions, and decide what deserves deeper investigation.

What Data Can Help You Do

Program review is strongest when data create a foundation for reflection rather than functioning as a compliance appendix. Look for patterns in participation, instructional activity, outcomes, and completions, then connect those patterns to program goals and local context.

Useful Data Mart Starting Points

  • Student Headcount for participation context
  • Course Details or Credit Courses/Sections for offerings
  • FTES for instructional activity
  • Success/Retention and Grade Distribution for course outcomes
  • Program Awards for completions
  • multi-year trend comparisons

What to Pair With Data Mart

  • local program goals and prior program reviews
  • curriculum and scheduling changes
  • student and faculty experience
  • local institutional research where Data Mart lacks the needed population
  • resource requests and action-plan follow-up

Questions to Bring to the Conversation

  • What changed since the last review?
  • Which patterns are persistent rather than one-year anomalies?
  • What can these data not explain?
  • What action would be reasonable to test next?
  • How will we know whether the action helped?

Important Boundary

Program review should not reduce program quality to one metric. Use multiple measures and qualitative context, and avoid treating a raw difference as a causal explanation.

Turn the Purpose Into a Query

If you know the decision or conversation but not the report, use Find the Right Report or CCC Data Mart Coach.
