Simple by design

Privacy and Data Safety

Data Mart Smart is a static educational website. It does not require an account and does not have a site database, analytics code, advertising trackers, or a server-side file upload feature.

Last reviewed: September 2026
Spreadsheet files are processed in your browser. Data Mart Smart does not send the contents of a selected spreadsheet to its own server. Use official aggregate Data Mart exports and do not select files containing personally identifiable or confidential records.

What the site stores

The current site has no account registration, contact form, application database, cookies, local storage, session storage, or analytics code. The Check My Query checklist also runs only in the browser and does not submit responses to Data Mart Smart.

Excel and CSV viewers

When you use a viewer, your selected file is read locally by browser-side JavaScript. Excel-reading pages load SheetJS Community Edition 0.20.3 from the official SheetJS CDN. That CDN can receive ordinary request metadata such as an IP address and browser information, but Data Mart Smart does not send your spreadsheet contents to the CDN. Requests use a no-referrer policy.

For security, the viewers accept only expected Excel or CSV file types, reject files larger than 10 MB, limit worksheet size, and disable unneeded spreadsheet features where the parser permits. Use files from trusted sources, preferably official CCCCO exports.

CCC Data Mart Coach

The Coach is hosted by Playlab. The embedded Coach does not connect to Playlab until you choose the Load button on the Coach page. If you use it, information you type, upload, or otherwise provide is handled through Playlab rather than the static Data Mart Smart site.

Do not share sensitive student or institutional information

Do not submit personally identifiable student records, protected educational records, credentials, passwords, confidential personnel information, or other restricted institutional information to the Coach or to a public website.

Hosting and external links

The hosting provider, such as GitHub Pages, can receive standard web-server request information needed to deliver the site. Links to CCCCO, Data Mart, Playlab, and other external services are governed by those services' own privacy practices. Data Mart Smart uses a site-wide no-referrer policy so external destinations are not sent the page URL as a referrer.

Future changes

If analytics, forms, accounts, server-side uploads, or other data-collecting features are added later, this notice should be reviewed before those features are made public.

Data Mart Smart

Data Mart Smart is an independent, faculty-led educational project. It is not an official California Community Colleges Chancellor's Office or CCC Data Mart product and is not funded, sponsored, or endorsed by those entities. Guidance may contain errors or become outdated as Data Mart changes. Verify consequential findings against current official CCCCO documentation and appropriate local institutional sources.
