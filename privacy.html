Home / Privacy

Simple by design

Privacy

The core Data Mart Smart website is designed as a static educational site and does not require an account to read its guides.

Last reviewed: September 2026

Information Collected by This Site

As currently designed, the core static website does not include account registration, a contact form, or a database that stores visitor-submitted information.

Interactive Checklist

The “Check My Query” checklist runs in the visitor's browser. The current version does not submit checklist responses to a server.

External Links

The site links to the official CCC Data Mart, CCCCO resources, and may link to other external services. Those services have their own privacy practices, which are outside this project's control.

CCC Data Mart Coach

The conversational coach is hosted through a separate service. Before the coach is embedded or linked publicly, this page should be updated with a clear description of that service's applicable privacy terms and what users should avoid sharing.

Do Not Share Sensitive Student Information

Do not upload personally identifiable student records, protected educational records, credentials, passwords, or other confidential institutional information to the coach or public site.

Future Changes

If analytics, forms, accounts, embedded tools, or other data-collecting features are added later, this notice should be revised before those features are made public.

Explore Data and Browser-Based Viewers

Explore Data and the legacy Program Awards Smart Viewer read a spreadsheet or CSV file you select using browser-side JavaScript. The selected file is not submitted to a Data Mart Smart server. These pages currently load the open-source SheetJS Community Edition library from jsDelivr so the browser can read Excel files.

Use these tools with public, aggregate Data Mart exports. Do not use them as a place to process student-level records, protected educational information, credentials, or other confidential institutional data.

Data Mart Smart

Data Mart Smart is an independent, faculty-led educational project. It is not an official California Community Colleges Chancellor's Office or CCC Data Mart product and is not funded, sponsored, or endorsed by those entities. Guidance may contain errors or become outdated as Data Mart changes. Verify consequential findings against current official CCCCO documentation and appropriate local institutional sources.
